# E-commerce Depósito Madeirão

Project under development.

This repository is an e-commerce application concept for **Depósito Madeirão**, aiming to provide a simple online shopping experience with product browsing, cart management, and order flow.

## Status
- 🚧 **In development** (work in progress)

## Basic Concepts (Planned)

### 1) Product Catalog
- List products with name, description, price, and images
- Product categories (optional)
- Product details page

### 2) Shopping Cart
- Add/remove products
- Update quantities
- Calculate subtotal/total

### 3) Checkout & Orders
- Customer information (name, phone, address)
- Order summary before confirmation
- Basic order creation and status tracking (planned)

### 4) Authentication (Optional / Planned)
- Admin area to manage products and orders
- User login/register (if needed)

### 5) Admin Management (Planned)
- Create/edit/delete products
- Manage inventory/stock (optional)
- View and update orders

## Goals
- Build a clean and easy-to-use shopping flow
- Keep the project modular for future improvements (payments, delivery tracking, etc.)
